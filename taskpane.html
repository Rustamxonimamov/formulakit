Keyboard shortcuts

Click a shortcut, then press the new keys (e.g. ⌘⌥P). Esc cancels. Changes save straight away.

Number keys work the same on English and Russian keyboards, so the shortcuts keep working when you switch layout.

Use ⌘, ⌥ or ⌃ together with a letter or number. Avoid keys macOS already uses, like ⌘Q, ⌘W, ⌘H or ⌘⌥D.
