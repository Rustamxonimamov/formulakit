Select a cell and press Precedents to see what it's made of, or Dependents to see where it's used.
Adds a "Map" sheet that labels every cell of the active sheet at the same address, and lists cells worth reviewing.

Number formats: #,##0 → 0.0 → 0.00 → % → x multiple → date → General.
Font colours: blue → green → black.
Auto-colour: typed numbers blue, links to other sheets green, other formulas black.
Borders: bottom line → total line → box → none.

⌘ = Command, ⌥ = Option. If Excel already uses a shortcut, it asks which one to keep.
